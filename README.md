# CritterBid

A responsive preview marketplace for birds, reptiles, amphibians and other exotic companion animals.

## Run

`npm start` (Node.js 18+). The app is a static front-end served by a small Node HTTP server.

## Current scope and limitations

This deployment is a **public preview**, not a production animal marketplace. Sample listings are fictional; saved listings are stored only in the visitor's browser. There are no real accounts, seller verification, published animal listings, live video, real-time bidding, messaging, payments, payouts, refunds, shipping or transfer workflows.

Before enabling real transactions: obtain species- and jurisdiction-specific legal/welfare review; implement a default-deny eligibility engine; verify seller identity, permits and source/health documents; add moderated persistent listings, audited server-authoritative auctions, secure messaging, incident handling and approved payment processing. Do not assume a payment provider permits this business model. See PRODUCTION_CHECKLIST.md.

Browsing is intended to be free. Possible revenue streams after approval include seller-side fees, promoted listings and sponsorships; revenue is not guaranteed.
